# NUMEQO downloads

Official Windows installers for NUMEQO.

Start at [the NUMEQO website](https://numeqo-pi.vercel.app/), create your account,
and complete your Business DNA and workflow setup. Download and install NUMEQO,
then sign in with the same account to load your saved business setup.

This repository distributes installers and their checksums. It does not contain
customer accounts, Business DNA, transactions, or the application's source code.

To check a downloaded Windows installer, compare its SHA-256 checksum with the
`SHA256SUMS.txt` file attached to that release.

## Updates

Each published version has its own release. The NUMEQO website points to the
verified current installer. Publishing a release does not automatically update
an already installed application.
